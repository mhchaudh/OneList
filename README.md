# OneList

OneList is a simple todo app with Clerk authentication and Convex real-time synchronization. Signed-out users can work locally, while signed-in users can access their todos across devices.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Clerk
- Convex

## Run Locally

Install the dependencies, then run these commands in separate terminals:

```bash
npm install
npx convex dev
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
